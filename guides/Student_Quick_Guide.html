CIRCUIT STUDIO · STUDENT QUICK GUIDE

Your first schematic, breadboard and simulation

Use with the four Kokoro-narrated GUI walkthroughs. Practice on the supplied teaching examples, then build and submit your own assigned CS and CE work.

Back to the video collection · Open Circuit Studio Core

1. Get oriented

  1. Open Circuit_Studio_Core.html in a desktop browser. Open Design labs and select CS or CE.
  2. Follow Design & Build → Measure → Submit. Open the reference and record your design choices.
  3. Choose Build my schematic. Connect the unwired parts yourself. Use Lab reference while working.
  4. Use Parts for components, Select to move a part, R to rotate, W to wire, Esc to end placement, and F to fit the drawing. Click a pin to start a wire, add bends, and finish on another pin.
  5. Use Return to CS/CE lab to enter measurements and notes. Editing a worksheet later does not rewrite the components; update the schematic values too.

The videos use actual Circuit Studio GUI captures with highlights and close-ups. General part-placement examples use a simple resistor divider. The current Core uses the three-stage lab flow above. Captured readings illustrate one saved teaching model; they are not guaranteed results for every device or design.

3. Assemble the breadboard

  1. Finish and save the schematic. Choose Breadboard or the lab’s Build my breadboard. Keep power off during assembly.
  2. Choose This circuit, place the parts, and connect one schematic node at a time. Five-hole terminal strips are connected internally; the center gap separates the two halves.
  3. Use Guide me for step-by-step help. Show placement previews a location. Do this step performs an assisted action; record that help if required.
  4. Confirm virtual transistor terminal mapping. On real hardware, verify the actual manufacturer pinout and the ZVN3310F adapter header.
  5. For the illustrated CS negative source bias, the source-bypass electrolytic’s positive end goes to 0 V and its negative end to VS. For CE, CIN positive goes to the positive base bias and CB positive to the R4/R5 junction. Check your actual DC polarities.
  6. Use Jumper wire, then Check / Doctor. Fix wrong holes, missing connections and terminal mappings.
  7. Attach CH1, CH2 and common leads. Turn power on only after checking the connections. Capture your own board as evidence.

4. Measure in the Simulate bench

  1. Open the lab’s DC check with the signal disabled. Record the actual quiescent voltages and current.
  2. For AC, use Sine, zero offset and 1 kHz. The generator amplitude field is peak volts: Vpp = 2 × Vpeak.
  3. Assign the input to CH1 and output to CH2. Both references use 0 V. The lab test buttons set these automatically for a suitable one-source transistor circuit.
  4. Press Run after changing a setting. Wait for stable results; increase settling time if needed. Read numerical Vpp values and the channel scales.
  5. For inversion, record signed gain as −Vout,pp / Vin,pp. Look for clipping and bias/headroom limits. For CE, inspect VC(t) versus VB(t) when a large output is requested.
  6. Repeat at 10 kHz with the same input first. Record the actual input, output, gain and any later change in amplitude.

5. Save and submit

  • File → Save as…: editable circuit project, including its saved virtual breadboard when present.
  • Save progress: portable course/lab backup. Keep a copy before closing or changing browsers.
  • Submit stage: download the report and circuit; attach your schematic, breadboard and labeled 1 kHz / 10 kHz waveform captures through the class site.
  • CS and CE are separate submissions. Leave unavailable measurements blank. Keep calculations, simulation and actual hardware evidence clearly identified.

Quick troubleshooting

SymptomCheck next
No waveformInput source selection, waveform, amplitude, assigned probes, ground, Run and wiring.
Flat −15 V on CS outputCH2 may be on the negative rail. Select VD / the drain node.
Gain looks wrong from trace heightRead the numerical Vpp values; the two channels may have different volts/div.
Small gainBias and transistor model, input coupling, bypass-capacitor connection and output loading.
Large-signal clipping or CE region limitReduce the input and inspect DC headroom; document the limit instead of forcing the output target.
Breadboard mismatchInspect Doctor’s named connection and actual hole groups, not just wire colors or part proximity.
